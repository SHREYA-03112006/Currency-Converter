# Currency Converter 💱
A simple and interactive **Currency Converter** web application built using **HTML, CSS, and JavaScript**. The project allows users to convert amounts between different currencies through an easy-to-use interface.

## 📌 Features
* 💱 Convert between different currencies
* 💰 Enter custom amounts
* 🌍 Support for multiple currencies
* 🔄 Easy currency selection
* 🎨 Clean and interactive user interface
* ⚡ Instant conversion results

## 🛠️ Technologies Used
* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript** – Conversion logic and interactivity
* **Currency API** – Fetching exchange rates

## 🎯 How to Use
1. Enter the amount you want to convert.
2. Select the **From** currency.
3. Select the **To** currency.
4. Click the conversion button.
5. The converted amount will be displayed.
